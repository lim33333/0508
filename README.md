# 🏆 인스타 최강 인플루언서는 누구인가?

## 1. 프로젝트 개요
인스타그램 인플루언서 데이터를 활용해 팔로워 수, 평균 좋아요, 참여율, 영향력 점수를 비교하고,
브랜드 마케팅 관점에서 어떤 계정을 주목해야 하는지 분석한 프로젝트입니다.

## 2. 분석 질문
1. 팔로워 수가 많으면 평균 좋아요도 많을까?
2. 팔로워 수가 많으면 영향력 점수도 높을까?
3. 팔로워 대비 실제 반응이 높은 계정은 누구인가?
4. 최강 인플루언서는 어떤 기준으로 정의해야 할까?

## 3. 데이터 설명
- **데이터 출처**: Top Instagram Influencers
- **데이터 크기**: 200행 (Rows)
- **주요 컬럼**: `rank`, `channel_info`, `influence_score`, `followers`, `avg_likes`, `60_day_eng_rate`, `total_likes`, `country`

## 4. 전처리 과정
- `country` 결측치를 None으로 대체
- 'k', 'm', 'b' 단위 등 문자열로 된 수치 데이터를 계산 가능한 숫자로 변환
- '%' 기호가 포함된 문자열을 소수형 데이터로 변환
- `engagement_rate` 파생변수 생성하여 참여율 분석에 활용

## 5. 주요 인사이트
1. **팔로워와 반응의 불일치**: 팔로워 수가 압도적으로 많아도 평균 좋아요가 낮은 계정이 다수 존재했습니다.
2. **영향력 점수의 한계**: 팔로워 수와 영향력 점수 간에는 약한 양의 상관관계가 있었으나, 마케팅 효율을 판단하기 위한 단독 기준으로는 부족했습니다.
3. **참여율 중심의 재평가**: '참여율(Engagement Rate)' 기준 상위 계정은 '팔로워 수' 기준 상위 계정과 전혀 다른 양상을 보였습니다. 

## 6. 사용 기술
- **Language**: Python
- **Library**: Pandas, Matplotlib, Seaborn
- **Tool**: Jupyter Notebook, GitHub

## 7. 회고
이번 프로젝트를 통해 단순히 표면적인 숫자(팔로워 수)를 비교하는 것이 아니라,
'참여율'이나 '실제 반응' 같은 목적에 맞는 의사결정 기준을 세워야 분석 결과가 완전히 달라질 수 있다는 점을 배웠습니다. 향후에는 특정 산업군(뷰티, 패션 등)의 데이터를 추가하여 도메인별 특징을 비교해보고 싶습니다.
